# Fake Job Posting Detector

ML model jo LinkedIn style job postings mein fraud detect karta hai.

## Results
- Accuracy: 98%
- Fake Job Recall: 66%
- Dataset: 17,880 job postings (EMSCAD)

## Tech Used
- Python, Pandas, NLTK
- TF-IDF, Random Forest
- SMOTE for class imbalance

## How to Run
1. Clone repo
2. pip install -r requirements.txt
3. Open fake_job_detector.ipynb
